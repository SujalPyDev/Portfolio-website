01 — POWER BI
$3,474profit · 54 sales orders
Median sales $222.50

Power BI Capstone — Retail Sales & Profit Dashboard

Microsoft Power BI Analyst capstone · Power BI · DAX · Power Query

Loaded sales, purchases and country data into Power BI and cleaned it in Power Query, then built Sales Overview and Profit Overview dashboards with country and date filters.

  • Converted all sales to USD so different countries could be compared fairly, using a 2020–2023 calendar and a star-schema model.
  • Created DAX measures for median sales, profit, and yearly / quarterly / YTD profit margin.
  • Result: $14,967 gross revenue, $13,895 net revenue, $3,474 profit. Cost was 75% of net revenue. UAE was highest at $5,465 in this 54-order sample.

  • Data Modelling
  • Star Schema

Adventure Works — Q1 Sales Analysis Dashboard

Excel capstone · Excel · SUMIF / SUMIFS / COUNTIF · Charts
